# 학사 데이터 모델

학생 맞춤형 답변에 필요한 학사 데이터를 Django ORM으로 관리한다. 이 모델은
학교 학사 시스템을 대체하지 않으며, 연동 데이터와 PoC용 Mock 데이터를 일관된
형태로 조회하기 위한 내부 모델이다.

## 모델 관계

- `Major`: 전공
- `AcademicTerm`: 연도와 학기로 구분되는 학기
- `Student`: 학번, 재학 상태, 주전공과 복수·부전공
- `Course`: 학기에 종속되지 않는 과목 기본 정보
- `CourseOffering`: 특정 학기에 실제로 개설된 과목의 분반
- `CourseMeeting`: 개설 강좌의 요일, 시간, 강의실
- `Enrollment`: 학생의 현재 또는 예정된 수강 정보
- `AcademicRecord`: 완료된 과목의 성적과 취득 학점

과목에는 전공·BSM·교양 이수 구분과 영어강의 여부를 저장한다. 성적 기록에는
재수강으로 대체되어 평점 계산에서 제외할 과거 기록인지 표시할 수 있다.

`Course`와 `CourseOffering`을 분리하여 동일 과목이 여러 학기와 분반으로 개설되는
경우를 정확하게 표현한다. 과목명이 나중에 바뀌어도 당시 성적표를 보존할 수 있도록
`AcademicRecord`에는 과목 코드와 이름의 스냅샷을 함께 저장한다.

## 데이터 정합성

학교의 수강 신청 규칙을 이 서비스에서 다시 구현하지 않는다. 대신 내부 데이터가
잘못 연결되는 것을 막기 위해 다음 항목만 보장한다.

- 같은 학생과 개설 강좌의 중복 수강 정보 방지
- 과목·학기·분반 및 학생·과목·학기·수강 차수 중복 방지
- 성적 기록과 연결된 개설 강좌의 과목·학기 일치 확인
- 날짜, 시간, 학점 등 기본 범위와 관계 제약 확인

## 확인 방법

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
```

Django Admin의 `학사 데이터` 영역에서 모든 모델을 조회하고 입력할 수 있다.
