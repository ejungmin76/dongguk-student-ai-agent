# 성적·이수내역 조회 Tool

`get_academic_records`는 Repository의 성적 기록을 기반으로 누적 평점과 취득학점을
결정론적으로 계산한다. Agent나 LLM은 평점 계산을 수행하지 않는다.

## 계산 규칙

- 재수강으로 대체된 과거 기록은 누적 평점과 취득학점 합계에서 제외한다.
- `grade_points`가 없는 P/F 과목은 취득학점에는 포함하고 평점 분모에서는 제외한다.
- F는 `grade_points=0`이고 신청학점이 있으므로 평점 계산에 포함한다.
- 평점은 `합계(과목 학점 × 평점) / 평점 대상 학점`으로 계산해 소수 둘째 자리로 반올림한다.

전체 결과와 함께 학기별·이수영역별 합계 및 개별 성적을 반환한다. `year`,
`semester`, `category` 입력으로 조회 범위를 제한할 수 있다.

권한은 Profile Tool과 동일하게 인증된 본인 조회가 기본이며, 서버가 명시적으로
부여한 권한 없이는 다른 학생을 조회할 수 없다.
