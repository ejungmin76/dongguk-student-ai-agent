# Mock 학생 시나리오와 Seed Data

Issue #8의 데이터는 동국대학교형 질문을 재현하기 위한 PoC 전용 데이터다.
실제 학생, 교수 또는 수업 정보를 복제하지 않는다.

## 실행

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_academic_data
```

명령은 `update_or_create`를 사용하므로 여러 번 실행해도 Mock 학생이 중복되지 않는다.

## 학생 시나리오

| Mock 학번 | 시나리오 |
|---|---|
| `MOCK-2026-001` | 1학기 신입생 |
| `MOCK-2026-002` | 3학기 일반과정 학생 |
| `MOCK-2026-003` | 4학기 심화과정 학생 |
| `MOCK-2026-004` | 5학기 심화과정 학생 |
| `MOCK-2026-005` | 6학기 데이터사이언스 복수전공 학생 |
| `MOCK-2026-006` | 7학기 심화과정·재수강 학생 |
| `MOCK-2026-007` | 3학기 진입 전 휴학 학생 |
| `MOCK-2026-008` | 119학점 취득 후 15학점 수강 중인 졸업 임박 학생 |

모든 이름은 `가상학생NN`, 학번은 `MOCK-...` 형식이다. 교수명과 강의실도
각각 `가상교수`, `가상강의실`로 저장한다.

## 사실과 가상값의 경계

공식 자료를 참고한 항목:

- `CSC2001` 기초프로그래밍, `CSC2007` 자료구조 등 학수번호와 과목명
- 컴퓨터·AI학부 일반과정의 주요 전공 및 BSM 과목
- A+~F 평점 체계와 재수강 시 기존 성적 대체 개념

PoC를 위해 가정한 항목:

- 학생 이름, 학번, 개별 성적과 수강 이력
- 교수명, 강의실, 분반, 정원과 수업 시간
- 공식 학수번호가 공개되지 않은 교양의 `MOCK-GEN-*` 코드
- 영어강의 여부(공식 강의시간표 연동 전에는 모두 미확인으로 처리)
- 학기 시작일과 종료일

공식 참고 자료:

- 동국대학교 「2026학년도 신입생을 위한 학사제도 및 학업이수 가이드」
- 동국대학교 학사제도 성적 안내
- 컴퓨터공학전공 교육과정 운영규정

이 데이터는 졸업 가능 여부를 확정하는 근거가 아니다. 입학연도별 졸업요건 계산은
별도의 결정론적 규칙 모듈에서 구현한다.

각 학생은 2026 교육과정이 적용된 독립 시나리오이며 `reference_term`이 그 학생의
현재 시점을 나타낸다. 이전 학기 과목은 `AcademicRecord`, 기준 학기의 과목은
`Enrollment`에만 저장한다. 따라서 미래 학기의 3·4학년 시나리오도 현재 학기와
혼동하지 않는다.
