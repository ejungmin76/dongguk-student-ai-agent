# 동국대학교 학생 맞춤형 AI Agent: 공식 제안용 목표 구조

## 현재 위치

현재 구현은 공개 학사 자료 27개, 검색 청크 989개, Gemini 임베딩, PostgreSQL pgvector 의미 검색, PostgreSQL FTS 정확 용어 검색까지 검증한 기술 기반이다. 이를 학교 운영 서비스로 제안할 때는 개인 학사 데이터와 공개 지식의 경계를 명확히 유지한다.

## 목표 구조

```text
학생 질문
  ├─ 명시 필터: 입학연도 / 전공 / 학기 / 시행 시점
  ├─ Dense 검색: 의미가 가까운 공식 근거 후보
  ├─ FTS 검색: 정확한 용어·과목 코드·성적 등급 후보
  ├─ Alias Registry: 승인된 공식 약칭만 데이터로 확장
  └─ Trigram 검색: 제목·섹션명 오타 후보
                 ↓
          Hybrid fusion + Reranker
                 ↓
     출처·시행시점이 포함된 답변 검증
```

## 용어·오타 정책

- 코드에 학과 약칭·동의어·한국어 불용어 목록을 넣지 않는다.
- `KnowledgeTermAlias`에는 별칭, 표준 용어, 공식 출처 URL, 승인 상태, 유효기간을 저장한다.
- `approved` 상태의 데이터만 검색어 확장에 사용한다. 검토 중인 제안은 답변 품질에 영향을 주지 않는다.
- 오타 보완은 `pg_trgm`의 문자 trigram 유사도로 제목·섹션명 후보를 찾는다. 오타 보정 결과는 필수 필터가 아니라 Hybrid 후보 신호다.
- 사용자가 명시한 입학연도·전공·학기·시점만 강한 필터로 사용한다. 자동 추출 용어는 후보 점수 신호다.

## 공식 운영에 필요한 발전 항목

| 우선순위 | 항목 | 완료 기준 |
|---|---|---|
| P0 | 문서 거버넌스 | 소유 부서, 검토자, 시행일, 폐기일, 승인 이력이 자료마다 남는다. |
| P0 | 검색 평가셋 | 실제 학생 질문 유형별 정답 근거와 Recall@k, MRR, 근거 정확도를 측정한다. |
| P0 | 출처 검증 | 답변은 공식 URL·문서 제목·시점 없이 확정적 안내를 하지 않는다. |
| P0 | 개인정보 경계 | nDRIMS 등 개인 정보는 학교 인증·권한·감사 체계 안의 별도 Tool에서만 조회한다. |
| P1 | Hybrid + Reranker | Dense/FTS/오타 후보를 합치고 질문-근거 적합도로 재정렬한다. |
| P1 | 용어 승인 워크플로 | 담당 부서가 Alias Registry를 Admin 또는 승인 화면에서 관리한다. |
| P1 | 문서 변경 감지 | 원문 해시 변경, 재수집, 재청크, 재임베딩, 이전 벡터 폐기 과정을 기록한다. |
| P2 | 한국어 분석 고도화 | 평가 결과가 부족할 때 형태소 분석 또는 전문 검색 엔진을 도입한다. |

## 제안 시 표현 원칙

현재 시스템은 학교 공식 시스템을 대체한다고 주장하지 않는다. 공개 자료 기반 안내와 검색 정확성 검증을 제공하고, 개인화 학사정보 연동은 학교의 인증·API·보안 검토가 완료된 뒤에만 단계적으로 적용한다.
