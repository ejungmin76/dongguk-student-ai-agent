# 현재 수강·시간표 조회 Tool

`get_current_schedule`은 학생의 `reference_term`과 일치하면서 상태가 `enrolled`인
수강 신청만 반환한다. 과목, 이수영역, 학점, 분반, 담당자, 요일, 시작·종료 시간,
강의실을 구조화한다.

- 수강 과목이 없으면 `success`와 빈 과목 목록, 0학점을 반환한다.
- 같은 요일의 두 수업 시간이 실제로 겹치면 `partial`과 `SCHEDULE_CONFLICT`를 반환한다.
- 시간이 맞닿기만 하고 겹치지 않는 경우는 충돌이 아니다.
- 다른 학생의 시간표는 별도 권한 없이는 조회할 수 없다.

Repository 단계에서 현재 기준 학기를 필터링하고 Tool 단계에서 총 신청학점과 시간
충돌을 계산한다. 실제 ADK Agent 등록은 ADK 초기 구축 이슈에서 진행한다.
